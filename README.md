# Agricultural Data Source Selection for Crop Yield Analysis

An advanced Multi-Attribute Decision Making (MADM) framework combining **Hesitant Fuzzy Sets** and **Rough Set Theory** to evaluate, rank, and select the optimal agricultural data sources for accurate crop yield prediction and analysis.

---

## 📌 Project Overview
Selecting the most reliable and informative agricultural data source is a critical challenge in crop yield modeling due to noise, incompleteness, and subjective uncertainty. 

This project implements a hybrid **Hesitant Fuzzy Rough Multi-Attribute Decision Making (HFR-MADM)** method:
- **Hesitant Fuzzy Sets (HFS):** Captures hesitance and ambiguity among decision-makers when evaluating source attributes (e.g., data accuracy, update frequency, sensor precision).
- **Rough Set Theory:** Handles boundary approximations and vagueness without requiring prior probabilistic assumptions.
- **MADM Evaluation:** Determines the relative attribute weights and produces an objective ranking of candidate agricultural data sources.
